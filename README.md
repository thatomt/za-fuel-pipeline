# ZA Fuel Pipeline: South African Fuel Price Intelligence

A data engineering project exploring historical South African fuel prices, inland-versus-coastal price differences and the relationship between fuel-price movements and food inflation.

## Project Overview

Fuel prices affect transportation and distribution costs across South Africa. This project aims to investigate how fuel prices differ between inland and coastal regions and whether changes in fuel prices are associated with changes in food inflation.

The project will use historical fuel-price data and economic data from reliable South African sources.

## Key Objectives

- Analyse historical South African fuel prices.
- Compare inland and coastal petrol prices.
- Investigate the relationship between fuel-price changes and food inflation.
- Compare food inflation with headline inflation.
- Build a reproducible data engineering pipeline.
- Store validated data in PostgreSQL.
- Generate analytical reports and visualisations.

## Data Sources

The project will investigate data from:

- Department of Mineral and Petroleum Resources (DMPR) – Historical South African fuel prices.
- Statistics South Africa (Stats SA) – Consumer Price Index (CPI) data.

Source coverage, file formats, licensing and data availability will be verified during the research phase.

## Important Note

This project is an observational analysis. Any relationship identified between fuel prices and inflation will not be interpreted as proof of causation.

All findings will be based on verified data processed through the pipeline.
